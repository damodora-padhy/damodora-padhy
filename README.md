## 🚀 Featured Project

### Smart Motorized Curtain System

An ESP32-based automated curtain system designed to control curtain movement using environmental and obstacle sensors.

**Key components:**
- ESP32 DevKit
- 2 × 28BYJ-48 Stepper Motors
- 2 × ULN2003 Motor Drivers
- IR Obstacle Sensor
- LDR Light Sensor
- FC-37 Rain Sensor
- DHT11 Temperature & Humidity Sensor
- Bluetooth Serial Control
- Blynk IoT

The system supports automatic sensor-based operation as well as manual control through Bluetooth and Blynk IoT.
